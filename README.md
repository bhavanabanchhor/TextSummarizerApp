# TextSummarizerApp
The Text Summarizer App is an AI-powered web application that converts long text and conversations into short, meaningful summaries using the T5 model. Built with Python, FastAPI, PyTorch, Hugging Face Transformers, HTML, CSS, and JavaScript, it helps users understand important information quickly and efficiently.
